# TypeScript 手册

# 关于本手册

在引入编程社区20多年后，JavaScript现已成为有史以来最广泛使用的跨平台语言之一。JavaScript最初只是一种用于为网页添加简单交互性的小型脚本语言，如今已发展成为各种规模的前端和后端应用程序的首选语言。尽管用JavaScript编写的程序在规模、范围和复杂性上呈指数级增长，但JavaScript语言表达不同代码单元之间关系的能力却没有相应提高。再加上JavaScript相当特殊的运行时语义，这种语言与程序复杂性之间的不匹配使得大规模管理JavaScript开发成为一项艰巨的任务。

程序员编写的最常见的错误类型可以描述为类型错误：在需要使用不同类型值的地方使用了某种类型的值。这可能是由于简单的拼写错误、未能理解库的API接口、对运行时行为的不正确假设或其他错误。TypeScript的目标是成为JavaScript程序的静态类型检查器——换言之，它是一种在代码运行（静态）之前运行的工具，确保程序的类型是正确的（经过类型检查）。

如果你没有JavaScript基础，打算将TypeScript作为你的第一门语言来学习，我们建议你先从微软的 `Learn JavaScript` 教程或 `Mozilla Web Docs` 上的JavaScript文档开始阅读。如果你有其他语言的经验，通过阅读手册，你应该能够很快掌握JavaScript语法。

# 内容架构

本手册分为两部分：

## 手册

  本手册旨在成为一份面向日常程序员的全面文档，用于解释 TypeScript。您可以通过左侧导航栏自上而下地阅读手册。

  你应该期望每一章或每一页都能让你对给定的概念有深入的理解。本手册并非完整的语言规范，而是旨在成为涵盖该语言所有特性和行为的全面指南。

  完成演练的读者应能够：

  - 阅读并理解常用的TypeScript语法和模式
  - 解释重要编译器选项的影响
  - 在大多数情况下能正确预测类型系统的行为
  - 为了确保清晰性和简洁性，本手册的主要内容不会深入探讨所涵盖功能的每个边缘情况或细节。有关特定概念的更多详细信息，请参阅参考文章。

## 参考

  导航中手册下方的参考部分旨在帮助您更深入地理解TypeScript特定部分的工作原理。您可以从头到尾阅读，但每个部分都旨在更深入地解释一个概念，这意味着并不追求连贯性。

# 非目标（Non-Goals）

本手册还旨在成为一份简明扼要的文件，读者可在几小时内轻松阅读。为保持篇幅简短，某些主题将不予涉及。

具体来说，本手册并未全面介绍JavaScript的核心基础知识，如函数、类和闭包。在适当的地方，我们会提供背景阅读链接，供您深入了解这些概念。

本手册也并非旨在替代语言规范。在某些情况下，为了提供更高级别、更易于理解的解释，我们会跳过边缘情况或行为的形式化描述。相反，手册中设有单独的参考页，更精确、更正式地描述了TypeScript行为的诸多方面。这些参考页并不适合不熟悉TypeScript的读者，因此其中可能会使用高级术语或提及您尚未阅读的主题。

最后，除非必要，否则本手册不会介绍TypeScript如何与其他工具交互。诸如如何使用webpack、rollup、parcel、react、babel、closure、lerna、rush、bazel、preact、vue、angular、svelte、jquery、yarn或npm配置TypeScript等主题不在本手册的涵盖范围内——你可以在网络上的其他资源中找到这些信息。
